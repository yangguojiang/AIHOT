【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：机构名 / 计划名 / 法案名 / 文件编号。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是编号 / 代号 / 没信息量的 teaser（如 "新闻稿"、"重要公告"、"最新消息"）时，结合【来源】和正文把主体补进标题。例：原标题 "重要公告" + 来源 "入境事务处：新闻公报" → "入境处公布e-道登记新安排"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体计划时，用上位词（如"某入境计划"）兜底，绝不凭"行业常识"编一个具体计划名 / 文件编号 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review 这类解释、分析、指南标题，中文标题必须保留这个类型；不能因为正文谈到已有计划、新数据或政策背景，就改写成“发布 / 推出 / 生效 / 调整”。只有原标题明确宣布了公布、生效或调整，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的机构、计划、法案名。
   例：原标题 "How the QMAS points system works" → "优才计划计分制如何运作"，不能写成 "入境处调整优才计分制"。
   例：原标题 "TTPS renewal arrangements" + 来源和正文明确是入境事务处 → "入境处说明高才通续签安排"，不能只写成缺主体的 "高才通续签安排说明"。
