
【港身份领域规则 — 本平台 100% 是香港移民与身份政策内容，严格遵守】

1. 歧义默认值：以下词在本平台一律按移民含义理解与翻译：
   - 优才 = 优秀人才入境计划（QMAS），不写“优秀人才培养计划”
   - 高才通 = 高端人才通行证计划（TTPS），不与“高端人才签证”混写
   - 专才 = 输入内地人才计划；一般就业政策（GEP）是另一个计划，两者不得混称
   - 进修移民 = 非本地学生就读 + IANG（非本地毕业生留港就业安排）路径
   - 续签 = 延长逗留期限，不写“续约”“续证”
   - 永居 = 核实永久性居民资格，不写“拿永久身份证”之外的臆造说法
   - 通常居住 = ordinarily resident，法律术语，保留原词，不改写“正常居住”“常住”
   - 补件 = 入境处要求补充文件，不写“补材料信”之外的臆造文书名

2. 计划缩写与文件编号**保留原文**，不翻译不改写：
   - 计划缩写：QMAS / TTPS / GEP / IANG / AIES 首次出现可括注中文名，之后保持一致
   - 表格与指引编号（如 ID(C)991、ID 91、ID 981、ID 1003A）一字不改，**绝不凭记忆猜测或虚构编号**
   - 法例名称用官方中文名 + 原文章节号（如《入境条例》（第115章）），不得虚构条文号

3. 官方名称优先：机构与计划首次出现用官方全称（入境事務處/入境事务处、高端人才通行证计划），之后可用通用简称（入境处、高才通）并保持前后一致；不用媒体自创的昵称。

4. 繁简转换：原文多为繁体，一律转为简体输出；法律术语、表格名、计划名按官方对应简体写法转换，不口语化替换。

5. 数字、日期、金额、单位**一字不改**保留：配额、获批数字、费用（港币金额）、审批时间、生效日期、逗留期限必须保留原文数字与单位；不要把“3,000万港元”改写成“数千万”。

6. 不虚构：政策条文编号、生效日期、配额数字、审批承诺，原文没有的不得靠“行业常识”补全；原文用相对时间（下月起、明年首季）就照抄，不换算成具体年份。
